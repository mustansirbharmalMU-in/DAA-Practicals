Algorithm: Linear Search

Aim:
To search for an element in an array by checking each element sequentially
from the first element to the last.

Input:
- Number of elements n
- Array of n elements
- Element to be searched (key)

Output:
- Index of the element if found, otherwise "Element not found"
- Execution time and complexity analysis

Steps:
1. Start
2. Read the number of elements n
3. Read n elements into array arr[]
4. Read the element to search (key)
5. Start timer
6. Set found = false
7. For i = 0 to n - 1, repeat steps 8 to 9
8.    If arr[i] == key then
         Set found = true
         Set position = i
         Break from the loop
9. Continue to next i
10. Stop timer
11. If found is true then
       Print "Element found at index position"
    Else
       Print "Element not found"
12. Print execution time
13. Print time and space complexity
14. Stop

Time Complexity:
- Best Case   : O(1)   (element found at first position)
- Average Case: O(n)
- Worst Case  : O(n)   (element not present or at last position)

Space Complexity: O(1)
