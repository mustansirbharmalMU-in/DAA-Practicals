Algorithm: Bubble Sort

Aim:
To sort an array in ascending order by repeatedly swapping adjacent elements
if they are in the wrong order.

Input:
- Number of elements n
- Array of n elements

Output:
- Sorted array in ascending order

Steps:
1. Start
2. Read the number of elements n
3. Read n elements into array arr[]
4. For i = 0 to n - 2, repeat steps 5 to 7
5.    For j = 0 to n - i - 2, repeat steps 6 to 7
6.       If arr[j] > arr[j + 1] then
7.          Swap arr[j] and arr[j + 1]
8. Print the sorted array
9. Stop

Time Complexity:
- Best Case   : O(n)     (already sorted, with optimization)
- Average Case: O(n^2)
- Worst Case  : O(n^2)

Space Complexity: O(1)
